Web technology is used to build websites.

HTML gives the structure of a page. CSS adds colors, fonts, spacing and layout. JavaScript makes the page interactive. Together they are used to create every website we see on the internet.

CSS3 adds new features like multicolumn layout, shadows, rounded corners and media queries. Media queries help a page look good on mobiles, tablets and desktops.
